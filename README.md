# SF Airbnb Listings

A JavaScript and DOM self-assessment project that loads Airbnb listing data from a local JSON file and displays the first 50 listings dynamically.

## Features

- Loads Airbnb listing data using `fetch()` and `async/await`
- Displays the first 50 listings from the JSON file
- Shows:
  - Listing name
  - Description
  - Amenities
  - Host name
  - Host photo
  - Price
  - Listing thumbnail
- Responsive layout using Bootstrap
- Creative feature: sort listings by price
  - Default order
  - Price: Low to High
  - Price: High to Low

## Technologies Used

- HTML
- CSS
- JavaScript
- ES6 Modules
- Bootstrap 5
- Fetch API
- GitHub Pages

## How It Works

The project uses the Fetch API with `async/await` to load Airbnb data from a local JSON file.

The first 50 listings are selected using JavaScript and rendered dynamically into the page using DOM manipulation.

The sorting feature uses an event listener to reorder the listings based on price.

## Run Locally

Clone the repository and open the project directory.
